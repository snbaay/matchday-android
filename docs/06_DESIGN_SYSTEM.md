# 06 — Дизайн: достаточно 30–60 минут до кода

## Принцип

**Да, дизайн продумать до программирования. Нет, не нужно сначала делать большой Figma-проект.** У вас техническая защита Android, а не UI-дизайн конкурс. Сначала фиксируем карту экранов, простой wireframe и дизайн-правила. Затем P4 реализует тему, остальные придерживаются её.

## Макеты (wireframe)

```text
[ Tournaments ]               [ SDU FIFA Cup ]
--------------------------    -----------------------------
[ + Create tournament ]       Teams: 4    Matches: 2
                             [ Teams       > ]
[ SDU FIFA Cup         > ]     [ Matches     > ]
[ Friends Cup          > ]     [ Standings   > ]
```

```text
[ Teams ]                     [ Matches ]
--------------------------    -----------------------------
[ + Add Team ]                [ + Create Match ]
 1. Real Madrid               Real Madrid  3 - 1 Barcelona
 2. Barcelona                 Arsenal      - : - Liverpool
 3. Arsenal
 4. Liverpool
```

```text
[ Edit score ]                [ Standings ]
--------------------------    -----------------------------
Real Madrid [ 3 ]             #  Team          P  W  D  L  GD Pts
Barcelona   [ 1 ]             1  Real Madrid   1  1  0  0  +2  3
[ Save score ]                2  Barcelona     1  0  0  1  -2  0
```

Верхняя стрелка Back для всех вложенных экранов. `TournamentList` — начальный экран, у него Back нет. Диалог добавления внутри Teams, создания турнира внутри Tournaments, матча внутри Matches.

## Правила P4

- Стиль: **спорт, но минимализм**. Одна основная тема: графитовый/тёмный фон, светлый читаемый текст, один зелёный/изумрудный акцент.
- Обычные Android Material 3 Card, Button, TextField, AlertDialog, TopAppBar.
- Цвета определять в `ui/theme/Color.kt`, типографику в `ui/theme/Type.kt`, применение в `Theme.kt`.
- Отступы по простой шкале: 8dp, 12dp, 16dp, 24dp; не задавать случайные размеры.
- Карточки с радиусом ~12–16dp, достаточные touch targets, длинные названия обрезать/переносить аккуратно.
- Избегать фотографий, сложных SVG, видео, анимации, поиска ассетов в интернете и зависимости от картинок.
- Пара минут на Figma/бумаге допустима, но не более одного короткого согласования. **Источник истины** — этот файл и контракт экрана.

## Кто владеет стилем

- P4 изменяет только `ui/theme/**` и собственные турнирные экраны.
- P3 создаёт общие `EmptyState` и `AppTopBar`, опираясь на Material 3 theme. Не хардкодить цвета.
- P2 делает матчевые и табличные экраны через `MaterialTheme.colorScheme`, без редактирования `Color.kt`.
- P1 не меняет тему ради интеграции, а сообщает P4 о нужных изменениях.

## Минимальный набор состояний для каждого экрана

- Empty list: дружелюбный текст, призыв к действию.
- Populated: работающие карточки/строки.
- Invalid input: небольшое сообщение об ошибке, без crash.
- Back navigation: возвращает туда, откуда пришёл пользователь.

**Дизайн считается готовым**, когда все четверо согласовали названия экранов, кнопок, цвета и основные карточки. Не тратьте день на логотип.
