# MATCHDAY · Assignments 8 & 9

Рабочий контекст команды для защиты Week 13. Продолжаем Android-приложение Week 12 и сохраняем MVVM. Источник требований — Assignments 8 & 9.pdf. Поиск и список «Мои клубы» — предложенный командный сценарий. Для поиска клубов используется OpenLigaDB.

## Что должно работать

- **Requirement 8.** Пользователь ищет клуб в Teams. Retrofit вызывает публичный REST endpoint из корутины. JSON преобразуется в Kotlin data classes, сетевой Repository передаёт данные через существующую архитектуру во ViewModel. Экран Compose наблюдает StateFlow. Во время запроса виден индикатор, при успехе — реальные клубы, при пустом ответе — сообщение, при ошибке — объяснение и Retry. Если API возвращает URL эмблем, показываем их через Coil.
- **Requirement 9.** Пользователь сохраняет найденный клуб в «Мои клубы», видит его в списке, редактирует заметку и удаляет запись. Для этого нужны Room Entity, DAO, класс базы и локальный Repository. Изменения поступают во ViewModel через Flow и отображаются в Compose. Порядок сортировки пользователь выбирает сам. DataStore сохраняет выбор. После закрытия и повторного запуска доступны сохранённые клубы, заметки и выбранный порядок.

HTTP-тест использует локальный сервер с подготовленными ответами. Поиск в приложении проверяем на устройстве после подключения экрана.

## Правила работы с проектом

Перед началом задачи по Week 13 прочитайте этот документ, README.md и актуальный код своей части.

Каждый участник должен понимать собственный код. Не создавать искусственные коммиты ради количества.
